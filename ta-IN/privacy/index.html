உங்கள் சாதனத்தில் பயன்படுத்தப்படும் தரவு

முன்னோட்டத்திற்கும் பேசுபவரைக் கண்டறிந்து பின்தொடர்வதற்கும் செயலி கேமரா காட்சிகளைப் பயன்படுத்துகிறது. பதிவு செய்யவோ வசனங்களை உருவாக்கவோ மைக்ரோஃபோனின் ஒலி அல்லது தேர்ந்தெடுத்த வீடியோவின் ஒலி பயன்படுத்தப்படுகிறது. இயல்புநிலையில் பேச்சறிதல் சாதனத்திலேயே நடைபெறும். மொழித் தரவு Apple-லிருந்து பதிவிறக்கப்படலாம். செயலியில் கணக்குகள், விளம்பரங்கள் அல்லது உருவாக்குநர் நடத்தும் செயலிக்குள் பயன்பாட்டுப் பகுப்பாய்வு இல்லை.

Apple வழங்கும் வெளிப்புறப் பேச்சறிதல்

இந்த முறையைத் தேர்ந்தெடுத்தால், பேச்சை அடையாளம் காண ஒலியும் அகராதியிலிருந்து பரிந்துரைக்கப்படும் சொற்களும் Apple-க்கு அனுப்பப்படலாம். சாதனத்திலேயே மீண்டும் செயலாக்க, செயலியின் அமைப்புகளில் பேச்சறிதல் முறையை மாற்றவும். Apple Privacy

சேமித்தலும் நீக்குதலும்

பதிவு வரைவுகள், வசனங்கள், அமைப்புகள் மற்றும் இறக்குமதி செய்த அகராதிகள் சாதனத்திலுள்ள செயலியின் சேமிப்பிடத்தில் வைக்கப்படலாம். செயலியை நீக்கினால் அதன் உள்ளூர்த் தரவும் நீக்கப்படும். ஏற்றுமதி செய்தவற்றை Photos அல்லது Files-ல் தனியாக நிர்வகிக்கவும். சாதன அமைப்புகளில் அனுமதிகளை மாற்றலாம்.

இணையதளமும் மின்னஞ்சலும்

இந்தத் தளம் GitHub Pages-ல் ஹோஸ்ட் செய்யப்படுகிறது. பாதுகாப்புக்காக GitHub பார்வையாளர்களின் IP முகவரிகளைப் பதிவு செய்கிறது. நீங்கள் மின்னஞ்சலில் அனுப்பும் தகவலை உங்கள் கோரிக்கைக்குப் பதிலளிக்கப் பயன்படுத்துகிறோம். GitHub Privacy Statement
